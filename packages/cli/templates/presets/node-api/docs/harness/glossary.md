# Glossário: Tasks API

| Termo | Significado | Não confundir com |
|-------|-------------|-------------------|
| Task | Unidade de trabalho do usuário | Todo genérico, Item, Card |
| ownerId | Dono da task | userId em outro bounded context |
| archive | Soft delete; task some da listagem ativa | delete físico sem regra |
| title | Rótulo curto da task | description (texto longo) |
