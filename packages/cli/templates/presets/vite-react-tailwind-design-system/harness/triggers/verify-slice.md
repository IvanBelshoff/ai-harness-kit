# Trigger: verificar fatia (SPA)

## Quando

Após componente ou página na fatia.

## Comandos

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

## Critério de pronto

- DoD do procedimento marcado

## Se falhar
