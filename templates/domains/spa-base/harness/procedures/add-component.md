# Procedimento: add-component

## Objetivo

Novo componente React alinhado ao glossário.

## Passos

1. Criar arquivo em `src/components/`.
2. Usar Tailwind e tokens existentes.
3. Adicionar teste smoke se lógica não trivial.
4. Rodar `harness/triggers/verify-slice.md`.

## DoD

- [ ] Componente exportado
- [ ] Verify verde

## Não fazer

- Refatorar App inteiro
- Introduzir lib de UI nova
